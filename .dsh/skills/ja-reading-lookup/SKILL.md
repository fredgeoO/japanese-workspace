# 日语自动解释（ja-reading-lookup）

## 0. 三层校验边界（先于一切检索动作）

解释任何日语素材前，先按内容类别决定「查不查、谁背书」。目的：把强校验收缩到库的强项上，
消除句级/语用层「整句无意义 `[模型推断]` 刷屏」的伪严谨。

**L1 强校验（必须检索、必须照抄库内结果，零例外）**——客观封闭事实，错一个字就误导记忆/跟读：

| 内容 | 检索方式 |
|---|---|
| 假名读音、音调 | `--dict`（reading / pitch 逐字照抄） |
| 词典释义、词频、语域标签 | `--dict` |
| 汉字音读/训读、笔画、部首、学年 | `--kanji` |
| 10 形态内标准活用 | `--conj` |
| 语法条目的接续/例句字段 | 整句模式 / `--grammar` 的 ✓ 字段 |

**L2 条件校验（仅库内命中时核对，未命中不硬凑）**：

- 受身/使役/可能形/口语省略等句法：库内 `hits` 命中对应句型条目（✓ 字段）时引用核对；
  未命中 → 直接按 L3 放手讲，不再逐点打 `[模型推断]`。
- 长句拆解：只对 `--dict` 命中的实词核对词义与读音；整句连贯理解与翻译属 L3。

**L3 放手（模型自然语境讲解，不检索、不逐点打标注）**——库的缺口，强行背书只会制造伪严谨：

- 近义词辨析、语用分寸、文体/敬语选择
- 惯用语/固定搭配的整体转义、新词俚语
- 10 形态以外的活用（受身/使役/可能/意志/条件）的变形说明
- 整句翻译与跨句语境理解

**标注规则（与三层对应）**：

- L1 照抄库内结果 → 挂对应 `[库内·可引用]` 类标注（第 7 节）。
- L2 命中 → **先过第 2.5 节功能对齐闸门**（同形 ≠ 同功能），过了才挂库内标注；未命中或闸门不过 → 转 L3。
- L3 → 正常讲解，**不再逐点打 `[模型推断]`**；仅当该处事实有争议或明显超出模型可靠范围时，
  在句末统一注明一句「此处为模型讲解，未经库内核对」。
- 红线不变：L1 的假名/读音/音调/释义永远不许凭记忆写；放手不等于放飞。

**熔断（降级）**：出现下列任一信号 → 按顺序砍层，每砍一层观察是否恢复：

1. 一次解释里 L1 检索明显拖慢对话节奏（如批量 `--dict` 卡住）→ 先只查用户问到的词，不跑整句全量。
2. 输出里「未经核对」类说明仍占讲解主体一半以上 → 砍 L2，退回「仅 L1 词级强校验，句级与语用全放手」。
3. 砍完后仍觉得检索是负担 → 保留 `--dict` 读音/释义核对这一项，其余全放手。
   恢复条件：用户明确要求"严格核对"时临时升回原层级。

## -1. 自动触发（最高优先级，先于一切判断）

**用户消息里只要出现日语内容，就自动按本 skill 流程解释，不需要用户说"解释/翻译/什么意思"这类请求词。**

- "日语内容"包括：单词、惯用句、句型、完整句子、歌词/台词、片假名外来语、文语、中日英混写中的日文部分——任何书写形式的日语都算。
- 触发后**不要反问**"你想让我做什么"。默认动作 = 解释这段日语（精读或快查按第 3 节判定）。
- 用户消息里若同时有中文指令（"这句语法什么来头""只查这个词"），按指令裁剪输出范围；检索范围按第 0 节三层边界裁剪——**L1 强校验层照跑照挂标注**，L2/L3 按边界决定查不查，不得因指令简单就跳过 L1 凭记忆作答。
- 唯一豁免：用户明确说"别解释/只是贴给你看/记一下"等非求解释意图时，才不跑解释流程。
- 输入是纯中文/纯英文、不含任何日语 → 不属于本 skill，正常对话即可。

## 2.5 引用准入闸门：同形 ≠ 同功能（2026-11-24 新增）

`hits` 只证明「库里有一条以同样字形为 key 的条目」，**不证明它就是句中这个功能的条目**。
事故样本（当时）：`値段も手ごろなら、アフターケアもきちんと…` 整句只命中**条件** `なら`，
句中实际是并列 `Aも〜なら、B〜も`；照抄条件释义 = 拿错义项背书，还要挂 `[语法书·表現文型]`。

引用任何 `★ 主条目` 前，三道闸全过才准挂库内标注：

| 闸 | 检查 | 不过怎么办 |
|---|---|---|
| ① 字形 | 条目 pattern 里那个词 = 句中该位置的词？ | 当没命中 |
| ② 功能 | 条目 `接续`/`语感` 讲的功能 = 句中此处承担的功能？ | 不得引用，转 L3 |
| ③ 同类优先 | 库里有没有更贴的条目（同功能的并行句型，或接续字段已覆盖该变体）？ | 先查一遍再下结论 |

第③闸的做法：把句中那段补回库里可能的句型名再查一次，别急着用同形条目。
例：句中 `値段も手ごろなら、…も` → `--grammar も〜ば` → 命中「も〜ば、〜も」[N3]，
其 `接续` ✓ 明写「Ｎも＋Ｖば／イＡければ／**ナＡなら／Ｎなら**＋Ｎも」——
这才是该引用的条目（并列表，不表条件）。
（2026-11-24 工具已补 `も〜なら、〜も` 变体键＋接续闸，这类句子整句 `hits` 会直接给出该条目且排第一；
但闸门规则不因此作废——别的同形词没有变体键，仍要自己按第③闸补查。）

**变体键从哪来**：`data/grammar_keys_extra.json`（`scripts/build_keys_extra.py` 离线生成，只增不改）。
每条都带 `basis`（授权它的是哪条接续字段原文）和 `guard`（运行时接续闸门）。想加新变体键：
先跑 `python scripts/build_keys_extra.py` 看候选表与跳过原因，确认后再 `--commit`——**别手改文件**。

**同形多功能高危词**（命中一条 ≠ 命中这个义项）：
`なら`（条件 / 并列）·`で`（だ的连用 / 格助词手段）·`と`（引用 / 条件）·`ながら`（同时 / 逆接）·
`ても`（让步 / 反复）·`から`（原因 / 材料）·`し`（并列理由）。判别法见第 6 节表 3。

三道任一不过：该条目**不得挂任何库内标注**（尤其不得挂 `[语法书·表現文型]`），按 L3 讲；
必要时写明「库内该功能收在 X 条目下」或「库内无该功能条目」。
**禁止**反过来用别的义项的条目给自己背书——那比不查更糟。

## 3. 模式判定（硬清单，按序判，命中即停；判不准一律走精读）

前提：第 -1 节已确认消息含日语并触发本 skill。只看用户消息里的**日语素材**，不看中文措辞：

0. 裸贴日语、无任何中文指令（只丢了一个词/一句话/一段歌词）→ 按素材形态走：整句/多句 → **精读**；单个词/惯用句 → **快查**；单个句型 → **快查**（`--grammar`）
1. 素材含完整句子（≥1 个句读点 。！？，且非纯引用词典例句）→ **精读**
2. 素材是「句子 + 某词」混合（"この『わけ』は何？全文も訳して"）→ **精读**
3. 素材只有 1 个词/惯用句 → **快查**（`--dict`）
4. 素材只有 1 个语法点/句型 → **快查**（`--grammar`）
5. 两个词/句型对比 → **快查**，两个都查
6. 以上都不像 → **精读**

**升级规则**：快查模式下 `--dict` 返回 0 条 → 立即升级为精读（把用户原话当句子跑整句模式）。

**兜底规则**：整句模式 `hits` 为空、分词也认不出（文语/歌词/生僻写法）→ 仍按精读模板输出：① 逐词解析照抄 CLI `tokens`，② 译文按 L3 放手正常给（不再逐点打 `[模型推断]`，句末统一注明一句「库内无命中，此处为模型讲解」），③ 语法点写明"库内无命中"，不得因检索空手而归就不解释。

## 4. 精读模式工作流

1. 跑 `python scripts/ja_lookup.py --json "<句子>"`，拿到 `tokens` 与 `hits`。
2. 对句中**值得学的实词**（生词、易读错、易望文生义的；常见到不会读错的虚词/基础词可略），把其 `dict_form` 批量喂 `--dict`（一次调用多个词）。L1 的读音/释义对查到的词一律照抄。
3. 按下面模板输出。

### 精读模板（2026-11-24 起精简：不再逐词全列）

**① 重点单词**：只挑值得学的词（生词、俚语缩略、易读错/易望文生义的），**不做逐词全列**。
- **假名列逐字照抄 CLI 的 `reading` 列（转平假名后），禁止自行改写、禁止替换形近搭配**（`しないか` 不得写成 `どうか`）。
- 词性照抄 `pos` 第一、二项。
- 释义：照抄 `gloss_zh` 中**与语境最贴合的 1–2 个义项**，禁止全抄长串。

**② 整句译文**：自然中文（L3 放手层，正常给，不逐点打标注）。
- **释义层与选词层分离**：词典义项是释义层；译文用词是选词层，可给"帮忙/配合"这类自然说法，但不得与释义层互相覆盖。
- **禁止把未完结动作拔高为完成态**：`聞きましょう` 是"听一听/我们一起听听"，不是"听完"。

**③ 语法点讲解**：对每个 `hits` 条目（L2 命中核对层）：
- **先过第 2.5 节三道闸**：条目讲的功能与句中此处不符（同形不同义项）→ 不引用，转 L3；
  别拿同形条目的释义顶替，也别为了"有个库内出处"硬挂标注。
- 条目 `接续` ✓ 若已覆盖句中变体（如「も〜ば、〜も」的接续含 `ナＡなら／Ｎなら`），
  可以引这条接续字段来支撑并列用法，挂 `[库内·可引用]`。
- 条目头带 `{接续✓ 语感✓ 例句✓}` 标记。**只引用打 ✓ 的字段；✗ 的字段走内置表或按 L3 放手讲，禁止补全。**
- 有条目带 `语感(中译):` 行时：中文可直接用，但**它是本地模型对英文 `语感:` 的转写，不是教材原文**，标注 `[库内·中译]`；两句冲突时以英文 `语感:` 为准。
- `EN:` 行是英文释义，可参考但输出中文时不得直译充数。
- 命中条目讲不到用户问的那个组合（如句中有 `だけは` 但命中里没有）→ 走第 6 节内置表 + 标注。
- 库内未命中的句法/语用点（受身使役、语气分寸等）→ 按 L3 放手自然讲解，不再逐点打 `[模型推断]`。

**④ 易错提醒**：只写有依据的坑（内置雷区表、库内 nuance 明确提到的对比），没有就不写，不硬凑。

**准入测试（每条逐行做）**：这行能指到出处吗？出处只有两种——
(a) 库内具体字段（`nuance`／`接续`／例句／词典 `注:`／语域标签／音调），(b) 第 6 节内置表的整行。
**指不到就删。**「汉字不一定要写汉字」「口语里常省略」这类没有出处的经验谈一律不写。
宁可只写一条，宁可不写——空着不算失分，编一条算作废。

**输出前自检（内部过一遍，不写进回答；任一条不过就重写）**：
1. 每个库内标注 → 能指到本轮 CLI 的某个字段吗？（第 7.1 节映射）
2. 每个被引用的语法条目 → 第 2.5 节三道闸都过了吗？
3. 每条易错提醒 → 有出处吗？

## 5. 快查模式工作流

`--dict WORD` 或 `--grammar PATTERN`，三段输出：

**① 词条/条目本体**：照抄检索结果（假名、词性、1–2 义项；语法条目照抄 ✓ 字段）。
**② 用法/辨析**：词典例句或语法 `○ 相关`/`· 对比参考` 层的内容**仅作辨析素材**；`★ 主条目` 是唯一权威主体。`▽ 兜底` 层带 `[裸条目·无讲解]`，**不得当讲解引用**，只能说明"库内该条目无讲解"。
**③ 例句**：只用检索返回的例句，禁止现编。

## 5.5 增强检索（四种情况按需补跑，不跑就别下结论）

| 遇到 | 跑 | 说明 |
|---|---|---|
| 句中变形看不出原形（受身/使役/使役受身/条件形/命令形） | `--conj <辞书形>` | 辞书形取整句 `tokens` 的 `dict_form`；活用表 10 个形态位（动词 9 个，形容词多一个连体形），**没有的形态（受身/使役/可能/意志/条件）不许说"库里有"**——10 形态内照抄（L1），表外的变形说明按 L3 放手讲规则，不逐点打标注 |
| 单字读音/熟语拆解存疑（「生粋」「相殺」这类） | `--kanji <字>` | 拿音读/训读原样照抄；训读里的 `しら.べる` 点号表示送假名分界，输出时保留原样，别自己改成「しらべる」 |
| 用户问「A 和 B 有什么区别」 | `--syn A` `--syn B` | **同一 synset 的成员 = 近义**，`上位` = 上位概念，`对义` = 反义。日语释义（`definition`）可直接引用，用来支撑辨析 |
| 词典例句太教材化、想要口语感 | `--sent <词>` | Tatoeba 日中对照，句短优先；引用时挂 `[Tatoeba 例句]`，译文照抄库里的 `zh` |

**音调与频度怎么用**：`音调: 0 型` = 平板型；`N 型` = 第 N 拍后下降（1 型 = 头高）。`zipf` 越高越常见（3.0 ≈ 每百万词 1 次），**只能用来判断"这词常不常见"，不能当难度等级或 JLPT 分级引用**。

## 6. 内置表（Skill 内置知识，非库内条目；输出引用时带 `[Skill 内置表]` 标注）

### 表 1：高频复合助词拆解（库内多为零收录或裸条目）

| 组合 | 拆解 | 固定说法 | 最小对比 / 雷区 |
|---|---|---|---|
| 〜だけは | だけ（限定）＋は（对比/提示） | 限定＋对比让步："别的可以不说，**至少这一项**要…" | `話だけ聞きましょう`＝单纯限定（只听故事）；`話だけは聞きましょう`＝限定＋让步（别的可以免了，至少听我说）。别把は丢进"主题"里糊过去 |
| 〜は別として | は（提示）＋別として（搁置） | "X 暂且不论（Y 另说）" | 库内 `別として` 是裸条目，讲解走本行 |
| 〜にしても | にしても（整体：让步） | "即使 X（也不改变结论）" | 与としても近义，にしても更接事实 |
| 〜こそ | こそ（强调提示） | "正是 X" | 与は对立：は对比/主题，こそ排他强调 |
| 〜しか〜ない | しか＋否定 | "只有 X（没有别的）" | しか 后必接否定，漏否定是经典错句 |
| 〜ては／では | て＋は（承接主题） | "一谈到 X 就…"／"那样的话…" | 表"一般标准"时读では（では困る），别混 |

### 表 2：句尾动作主体归属（视角反转雷区）

| 句尾 | 动作主体 | 说明 |
|---|---|---|
| 〜ましょう | **含说话人**（"我们一起…"/"我来…"） | 禁止译成"（你）听我说"这类把主体推给对方的说法 |
| 〜てください | 对方执行，说话人请求 | 主体是"你" |
| 〜てあげる | 说话人→对方（恩惠） | 对上级用会失礼 |
| 〜てもらう | 对方→说话人（受恩） | 主体是"对方" |
| 〜ておく | 说话人自己预先准备 | 别译成"替你做" |

### 表 3：同形多功能速判（配合第 2.5 节闸门用）

| 词 | 功能 A | 功能 B | 判别法 / 雷区 |
|---|---|---|---|
| なら | **条件**：承接对方的话或假定情境，主句给建议·判断（京都へ行くなら、秋がいい） | **并列**：`Aも〜なら、B〜も`＝"不但 A 而且 B"（値段も手ごろなら、味もいい） | 并列表能换成「〜で、」意思不变，前后互不依赖；条件なら 前后有依赖、主句必是建议/判断。**库内锚点：`--grammar も〜ば` →「も〜ば、〜も」[N3]，接续 ✓ 含 ナＡなら／Ｎなら** |
| で | **だ的连用形**：ナ形容词/名词并列·中顿（静かで便利だ／学生で、働いている） | **格助词**：手段·场所·材料·原因（ペンで書く／風邪で休んだ） | 前面是ナ形容词/名词且与后面属同一谓语的并列 → 连用形；后面是独立动作或事件 → 格助词 |
| と | **引用·思考内容**（〜と思う／言う／見る／感じる） | **条件**：必然·恒常（春になると花が咲く） | 后接 思う/言う/見る 等 → 引用；后接一般事实或反复现象 → 条件 |
| ながら | **同时进行**（歩きながら話す） | **逆接·让步**（残念ながら／知っていながら） | 前接ます形 → 同时；前接普通形且后接遗憾/矛盾 → 逆接 |
| から | **起点·原因**（タバコから火事／風邪から） | **材料**（米から作る） | 后接 作る/できる/なる → 材料；其余多为原因/起点 |
| し | **并列理由**（安いし、便利だし） | 与 `も〜ば` 分工：`し` 列**理由**，`も〜ば` 列**同类事实** | 库内「も〜ば、〜も」语感 ✓ 明写"对比〜し，后者列举原因" |

## 8. 红线（违反任何一条 = 输出作废重写）

1. **假名零幻觉（L1，永不放手）**：输出里所有假名必须来自 CLI `reading` 列或词典 `reading` 字段，逐字照抄。
2. **视角不反转**：句尾主体按表 2；`ましょう` 永远含说话人。
3. **汉语词不望文生义**：`検討`≠"讨论"（=斟酌/审议）、`勉強`≠"学习"（=用功/学一学）一类，拿不准就查 `--dict` 照抄释义。
4. **复合助词不吞并**：句中出现表 1 组合而 hits 未覆盖 → 必须拆解 + 标注，禁止当作"没讲头"跳过。
5. **不补全库内缺失字段**：✗ 字段 = 库里没有，不是让你编。
6. **不虚构 CLI 参数**：只有第 2 节列出的那些。
7. **活用表不越界**：`--conj` 只有 10 种形态，受身/使役/可能/意志/条件形库里没有 → 按 L3 放手讲规则，但别说成库内条目。
8. **音调不解释成别的**：`N 型` 只表示"第 N 拍后下降"，不许引申成"重音在第 N 个词"，也不许把 `0,2 型` 简化成一个数字。
9. **中译不当原文**：`语感(中译)` / 汉字 `中:` 是模型转写，可以用、可以引，但必须标 `[库内·中译]`，不得说成"教材/词典原文"，也不得在中译之外自行扩写讲解。
10. **放手不等于放飞**：L3 只免检索与逐点标注，不免第 1/2/3/8 条这类事实红线——读音、音调、视角主体在任何层都不许凭记忆编。
11. **标注可溯源**：每个 `[库内·…]`/`[语法书·…]` 标注都必须能在本轮 CLI 输出里指到一个具体字段；指不到就降级为 `[模型推断]` 或删（第 7.1 节）。
12. **引用须功能对齐**：命中条目与句中使用功能不符（同形不同义项）→ 不得引用、不得挂库内标注（第 2.5 节）。借错义项背书比不查更糟。
13. **提醒须有出处**：易错提醒每一行必须指到库内字段或内置表整行，指不到就删（第 4 节④）。

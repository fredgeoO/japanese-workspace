# 日语自动解释（ja-reading-lookup）

## -1. 自动触发（最高优先级）

**用户消息里只要出现日语内容，就自动解释，不需要"解释/翻译"等请求词，也不要反问。**

- 日语内容：单词、惯用句、句型、句子、歌词/台词、片假名外来语、文语、中日英混写中的日文部分。
- 有中文指令（"只查这个词"）→ 按指令裁剪输出范围，但 L1 强校验照跑，不得凭记忆作答。
- 唯一豁免：用户明确说"别解释/只是贴一下/记一下"。纯中文/纯英文输入不触发。

## 0. 三层校验边界

| 层 | 内容 | 规则 |
|---|---|---|
| **L1 强校验** | 假名读音、音调、词典释义、词频/语域、汉字音训/笔画、10 形态内活用 | 必须检索、必须照抄库内结果，零例外。错一个字就误导记忆 |
| **L2 条件校验** | 受身/使役/可能形/口语省略等句法、长句拆解 | 库内 `hits` 命中对应条目（✓ 字段）才引用核对（先过第 2.5 节闸门）；未命中转 L3 |
| **L3 放手** | 近义辨析、语用/敬语、惯用语整体义、10 形态外活用的变形说明、整句翻译 | 模型自然讲解，不检索、不逐点打标注 |

- **熔断**：检索明显拖慢对话节奏 → 只查用户问到的词，其余放手。
- 红线不变：L1 的假名/读音/音调/释义永远不许凭记忆写；放手不等于放飞。

## 0.5 环境（已就绪，勿再安装）

工作区自带 `.venv/`（sudachipy 已装好）。**所有命令一律用**：

```
.venv\Scripts\python.exe scripts/ja_lookup.py ...
```

不要用系统 `python`（没装分词依赖）。冷启动 0.3s（词典）/ 0.8s（整句），检索必跑，不是成本问题。

## 2. CLI（只有这些参数，不得虚构其他参数）

```
.venv\Scripts\python.exe scripts/ja_lookup.py --json "完整句子"   # 整句：tokens + hits（每条带 _span=[起,止] token 窗口）
.venv\Scripts\python.exe scripts/ja_lookup.py --dict 徹夜 聞く     # 词典（音调/频度/语域/关联/反义）
.venv\Scripts\python.exe scripts/ja_lookup.py --grammar ましょう   # 语法条目（★主条目/○相关/·对比参考 三层）
.venv\Scripts\python.exe scripts/ja_lookup.py --conj 聞く          # 活用表（10 形态）
.venv\Scripts\python.exe scripts/ja_lookup.py --kanji 検          # 汉字
.venv\Scripts\python.exe scripts/ja_lookup.py --syn 検討           # WordNet 辨析
.venv\Scripts\python.exe scripts/ja_lookup.py --sent 言葉          # Tatoeba 真实例句
```

查询类参数可加 `--limit N`；整句模式可加 `--max-hits N`（默认 4，噪音多调小、怕漏调大）。

**degraded**：整句 `--json` 顶层带 `"degraded"` 字段；为 `true` 时（库文件损坏等）跳过强校验，按模型讲解输出并在句末注明「离线检索库暂不可用」。

## 2.5 引用准入闸门：同形 ≠ 同功能

`hits` 只证明「库里有条目以同样字形为 key」，**不证明它就是句中这个功能**。
事故样本：`値段も手ごろなら、アフターケアも…` 命中**条件** `なら`，句中实为**并列** `Aも〜なら、B〜も`——照抄条件释义＝拿错义项背书。

引用任何 `★ 主条目` 前，两道闸全过才准挂库内标注：

| 闸 | 检查 | 不过怎么办 |
|---|---|---|
| ① 字形 | 条目的命中 `_span` 就是句中该位置？（整句 `--json` 已给出 token 窗口，指到 tokens 里核对） | 当没命中 |
| ② 功能 | 条目 `接续`/`语感` 讲的功能 = 句中此处承担的功能？ | 不得引用，转 L3 |

同形多功能高危词：`なら`（条件/并列）·`で`（だ的连用/格助词）·`と`（引用/条件）·`ながら`（同时/逆接）·`ても`（让步/反复）·`から`（原因/材料）·`し`（并列理由）。**判别法见第 6 节表 3**。库里可能有更贴的并行句型时，先 `--grammar <句型名>` 补查再下结论。

闸门不过：不得挂任何库内标注（尤其 `[教材]`），按 L3 讲；必要时写明「库内该功能收在 X 条目下」。**禁止**用别的义项条目背书——比不查更糟。

## 3. 模式判定（按序判，命中即停；判不准走精读）

0. 裸贴日语无中文指令 → 整句/多句=精读；单词/惯用句=`--dict` 快查；单句型=`--grammar` 快查
1. 素材含完整句子（≥1 句读点）→ 精读
2. 句子＋某词混合 → 精读
3. 只有 1 词/惯用句 → 快查；4. 只有 1 句型 → 快查；5. 两词/句型对比 → 快查（都查）
6. 都不像 → 精读

**升级**：快查 `--dict` 返回 0 条 → 升级为精读（原话跑整句模式）。
**兜底**：整句 hits 为空、分词也认不出（文语/歌词/生僻写法）→ 仍按精读模板输出，句末统一注明「库内无命中，此处为模型讲解」，不得因查不到就不解释。

## 4. 精读模式

1. `--json "<句子>"` 拿 `tokens` 与 `hits`（已按相关度排序、默认截 4 条；无关命中直接忽略，优先采纳排前面的）。
2. 对**值得学的实词**（生词、易读错、易望文生义；基础词可略）批量喂 `--dict`，读音/释义照抄。
3. 按模板输出：

**① 重点单词**：只挑值得学的，不做逐词全列。假名列逐字照抄 CLI `reading`（转平假名后），禁止改写、禁止替换形近搭配；词性照抄 `pos` 前两项；释义照抄 `gloss_zh` 中与语境最贴合的 1–2 个义项。

**② 整句译文**：自然中文（L3 放手）。释义层与选词层分离；**禁止把未完结动作拔高为完成态**（`聞きましょう`="听一听"，不是"听完"）。

**③ 语法点**：对每个 `hits` 条目先过 2.5 闸门。条目头 `{接续✓ 语感✓ 例句✓}`——**只引用打 ✓ 的字段，✗ 的禁止补全**。`语感(中译):` 行是本地模型转写英文的产物，可用但挂 `[中译]`，与英文 `语感:` 冲突时以英文为准。命中讲不到的组合（如 `だけは`）→ 走第 6 节表 1。库内未命中的句法/语用点按 L3 放手讲。

**④ 易错提醒**：只写有出处的坑（内置表、库内 nuance 明确对比），没有就不写。

**发出前自检（一行）**：每个标注能指到本轮 CLI 的某个字段吗？每个语法引用过闸门了吗？指不到就删。

## 5. 快查模式

`--dict WORD` 或 `--grammar PATTERN`，三段：① 词条/条目本体（照抄，语法条目只引 ✓ 字段）② 用法/辨析（`○ 相关`/`· 对比参考` 仅作辨析素材，`★ 主条目` 才是主体；`▽ 兜底` 层是裸条目，不得当讲解引用）③ 例句（只用检索返回的，禁止现编）。

## 5.5 增强检索（按需补跑，不跑就别下结论）

| 遇到 | 跑 | 说明 |
|---|---|---|
| 变形看不出原形 | `--conj <tokens 的 dict_form>` | 10 形态内照抄；**受身/使役/可能/意志/条件形库里没有**，变形说明按 L3 讲，别说成库内条目 |
| 单字读音/熟语存疑 | `--kanji <字>` | 音训照抄；`しら.べる` 点号是送假名分界，保留原样 |
| 「A 和 B 什么区别」 | `--syn A` `--syn B` | 同 synset 成员=近义，`上位`/`对义` 可直接引用支撑辨析 |
| 想要口语感例句 | `--sent <词>` | 译文照抄库里 `zh` |

**音调**：`0 型`=平板；`N 型`=第 N 拍后下降（1 型=头高）。**zipf** 越高越常见，只用来判断常不常见，不当难度/JLPT 分级。

## 6. 内置表（Skill 内置知识，引用时挂 `[内置表]`）

### 表 1：高频复合助词拆解（库内多为零收录或裸条目；句中出现而 hits 未覆盖 → 必须拆解＋标注，禁止跳过）

| 组合 | 拆解 | 固定说法 | 最小对比 / 雷区 |
|---|---|---|---|
| 〜だけは | だけ（限定）＋は（对比/提示） | 限定＋让步："别的可以不说，**至少这一项**要…" | `話だけ聞きましょう`＝单纯限定；`話だけは聞きましょう`＝限定＋让步。别把は糊进"主题" |
| 〜は別として | は（提示）＋別として（搁置） | "X 暂且不论（Y 另说）" | 库内 `別として` 是裸条目，讲解走本行 |
| 〜にしても | にしても（整体：让步） | "即使 X（也不改变结论）" | 与としても近义，にしても更接事实 |
| 〜こそ | こそ（强调提示） | "正是 X" | は对比/主题，こそ排他强调 |
| 〜しか〜ない | しか＋否定 | "只有 X" | しか 后必接否定，漏否定是经典错句 |
| 〜ては／では | て＋は（承接主题） | "一谈到 X 就…"／"那样的话…" | 表"一般标准"读では（では困る） |

### 表 2：句尾动作主体归属（视角反转雷区）

| 句尾 | 动作主体 | 说明 |
|---|---|---|
| 〜ましょう | **含说话人**（"我们一起…"/"我来…"） | 禁止译成"（你）听我说" |
| 〜てください | 对方执行，说话人请求 | 主体是"你" |
| 〜てあげる | 说话人→对方（恩惠） | 对上级用失礼 |
| 〜てもらう | 对方→说话人（受恩） | 主体是"对方" |
| 〜ておく | 说话人自己预先准备 | 别译成"替你做" |

### 表 3：同形多功能速判（配合 2.5 闸门）

| 词 | 功能 A | 功能 B | 判别法 |
|---|---|---|---|
| なら | **条件**：承接对方话或假定，主句给建议·判断（京都へ行くなら、秋がいい） | **并列**：`Aも〜なら、B〜も`＝"不但 A 而且 B" | 并列可换「〜で、」意思不变、前后互不依赖；条件なら前后有依赖、主句必是建议/判断。**库内锚点：`--grammar も〜ば` →「も〜ば、〜も」接续 ✓ 含 ナＡなら／Ｎなら** |
| で | **だ的连用形**：ナ形/名词并列中顿（静かで便利だ） | **格助词**：手段·场所·材料·原因（ペンで書く） | 前接ナ形/名词且与后同一谓语并列→连用形；后接独立动作→格助词 |
| と | **引用·思考**（〜と思う／言う／見る） | **条件**：必然·恒常（春になると花が咲く） | 后接思う/言う→引用；后接一般事实→条件 |
| ながら | **同时**（歩きながら話す） | **逆接**（残念ながら／知っていながら） | 前接ます形→同时；前接普通形且后接遗憾→逆接 |
| から | **起点·原因**（風邪から） | **材料**（米から作る） | 后接作る/できる/なる→材料；其余多为原因/起点 |
| し | **并列理由**（安いし、便利だし） | 与 `も〜ば` 分工：`し` 列理由，`も〜ば` 列同类事实 | 库内「も〜ば、〜も」语感 ✓ 明写 |

## 7. 来源标注（4 种；L3 放手内容不逐点挂）

```
[库内]    照抄 CLI 字段：--dict 的 reading/音调/释义/注/标签、--conj、--kanji、--syn、--sent
[教材]    命中条目 sources 含 anki_besshiki（唯一中文教材源）
[内置表]  第 6 节某一行
[中译]    `语感(中译)` / 汉字 `中:`——模型转写自库内英文，非教材原文，不得在其外扩写
```

L3 放手内容不逐点挂；需要时在句末统一注明一句「此处为模型讲解，未经库内核对」。
**禁止写"库内未收录"**——被闸门滤掉的条目库内其实存在；确认零收录要跑 `--grammar <组合>` 看是否返回"库内无匹配条目"。

**库缺口登记（收窄）**：只在**用户明确追问"库里有没有"**且确认无该功能条目时，往 `skills/ja-reading-lookup/GAPS.md` 追加一行（日期/句子/缺什么/复现命令）。日常自动解释不登记。

## 8. 红线（违反任何一条 = 输出作废重写）

1. **假名零幻觉**：输出里所有假名必须来自 CLI `reading` 字段，逐字照抄（任何层都不例外）。
2. **视角不反转**：句尾主体按表 2；`ましょう` 永远含说话人。
3. **汉语词不望文生义**：`検討`≠"讨论"、`勉強`≠"学习"一类，拿不准就 `--dict` 照抄。
4. **中译不当原文**：`语感(中译)`/`中:` 必须挂 `[中译]`，不得说成教材/词典原文，不得在其外扩写。
5. **不补全库内缺失字段、不虚构 CLI 参数**：✗ 字段=库里没有；参数只有第 2 节那些。
6. **引用须功能对齐**：条目功能与句中此处不符（同形不同义项）→ 不得引用、不得挂库内标注（2.5 闸门）。借错义项背书比不查更糟。
